# 阶段 8：Nanobot 原生 MES 只读集成

## 已接入工具

| Nanobot 工具 | MES 查询 |
| --- | --- |
| `get_production_overview` | 全厂 dashboard 概览 |
| `get_line_status` | 产线状态、设备、告警和工单 |
| `get_device_status` | 设备状态与遥测 |
| `get_active_alarms` | 活动告警及过滤 |
| `get_work_order_progress` | 工单进度 |
| `get_delay_risk` | 工单延期风险 |
| `get_simulation_snapshot` | 仿真快照 |
| `get_strategy_result` | 策略仿真结果 |

实现文件：`nanobot/nanobot/agent/tools/mes.py`。该模块使用 Nanobot 原生
`ToolLoader` 自动发现，不需要复制或删除上游源码。

## 配置

将以下内容合并到 `~/.nanobot/config.json`，不要覆盖原配置：

```json
{
  "tools": {
    "mes": {
      "enable": true,
      "baseUrl": "http://127.0.0.1:3000/api/v1/agent-api/tools/execute",
      "tenantId": "tenant-demo",
      "requestedBy": "nanobot",
      "timeoutSeconds": 10
    }
  }
}
```

每次请求自动携带：

```json
{
  "tenantId": "tenant-demo",
  "requestedBy": "nanobot",
  "traceId": "current-turn-id"
}
```

## 启动与验证

先启动 MES 后端：

```bash
cd /Users/a1/Documents/ChatGPT/mes/backend
npm run start:dev
```

再启动 Nanobot：

```bash
cd /Users/a1/Documents/ChatGPT/mes/nanobot
uv venv --python 3.11
uv pip install --python .venv/bin/python -e '.[dev]'
source .venv/bin/activate
nanobot agent
```

测试和编译检查：

```bash
python -m pytest tests/tools/test_mes_tools.py
python -m compileall -q nanobot
```

## 明确禁止

本适配器只读，以下能力不会注册，也不能通过 MES Tool API 调用：

- 启动或停止设备
- 自动停线或恢复故障
- 修改、删除或报工工单
- 确认、关闭或修改告警
- 执行策略候选方案
- 直接发布 MQTT 控制消息

策略工具只返回候选结果；如需审批执行，必须另行设计权限、确认、审计和
回滚协议。
