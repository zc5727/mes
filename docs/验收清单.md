## 7. 最终冻结

进入演示验收的最低条件：

- 前端构建通过。
- Tauri wrapper 结构 smoke 通过。
- 至少一个平台的 app/dmg 已生成。
- Web API 和 MQTT 内存链路有基础证据。

进入生产冻结的必要条件：

- PostgreSQL 真实落库和重启恢复通过。
- MQTT、前端、Tauri 故障恢复通过。
- 权限、确认和审计闭环通过。
- 图纸、表单和策略结果边界明确。
- 生产 MQTT ACL/TLS、签名更新和回滚通过。
- 所有 P0 关闭，P1 有结论。

当前结论：可演示候选版本，不是生产交付版本。
