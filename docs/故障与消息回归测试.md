# 故障、消息与数据契约回归测试

## 覆盖范围

- 故障生命周期：多故障并存、按故障清除、通信中断恢复。
- 重复消息：重复故障投递不重复累积活动告警；暂停期间待发送告警只消费一次；无待发送告警时单次 tick 的 telemetry/snapshot topic 不重复。
- 离线恢复：设备被标记为 `offline` 后，带时间戳的 telemetry 将其恢复为 `online` 并刷新 `lastSeenAt` 与 metrics。
- OEE：停机时间不计入 operating time；可用率、性能、质量和 OEE 保持在合法范围；缺陷数满足总数分解关系。
- 数据契约：REST 租户信封、设备字段与错误状态；模拟器 MQTT topic、事件和 payload；产线配置的稳定 ID 与唯一性。
- 网络与回放：可配置断网/丢包、延迟、重复消息；场景事件和固定 seed 回放帧可重复导出。
- 策略仿真：只读输入快照、产能转移、设备故障、物料短缺和延期风险建议。
