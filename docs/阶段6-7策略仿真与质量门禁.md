## 阶段 6：只读策略仿真

独立目录：`/Users/a1/Documents/ChatGPT/mes/simulator/src/strategy`

入口为 `simulateStrategy(input)`，输入为时间、产线、订单和物料库存的快照，输出固定包含：

- `expectedCompletionAt`：全部可排订单的预计完成时间；存在物料或产能阻塞时为 `null`。
- `delayRisk`：`LOW`、`MEDIUM` 或 `HIGH`。
- `affectedOrders`：转移、延期、物料阻塞或设备影响到的订单。
- `lineLoads`：每条产线的既有负载、承接数量、可用产能、负载率和可用时间。
- `recommendations`：故障转移、负载均衡、物料短缺、维修恢复和延期缓解建议，并带推荐原因。
- `mode: READ_ONLY` 与 `executionAllowed: false`：结果没有执行动作字段，不调用业务控制接口。

仿真覆盖：

1. 优先产线停机或多设备故障后的兼容产线转移。
2. 多条兼容产线按预计负载率分配订单。
3. 物料不足时阻塞订单，不虚构完成时间，也不自动采购或领料。
4. 维修产线按 `recoveryAt` 恢复后再计算产能和交期风险。

## 阶段 7：回放与故障门禁

`replayOperationalMessages(messages)` 是独立的只读消息回放器，按租户、产线、设备和消息顺序处理输入，输出稳定的回放指纹。门禁覆盖：

- 单设备与多设备故障、产线停机。
- MQTT 断开、重连、重启，以及断开期间消息忽略。
- 重复消息和延迟消息分类，不覆盖最新状态。
- 离线恢复、物料短缺、质量异常。
- 多线并行状态聚合。
- 相同输入生成相同 `replayFingerprint`，支持可复现回放。
