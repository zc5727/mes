# 数字孪生前端交互回归清账

## 环境

- 前端：Vite `http://localhost:5173/`
- 后端：NestJS `http://localhost:3000`
- 浏览器视口：1280 × 720
- 数据源：API POLLING，租户 `tenant-demo`
- 检查方式：浏览器交互、DOM 状态、控制台日志和截图

## 控制台观察

未发现 JavaScript `error`。页面曾记录多条：

```text
MES API refresh failed, keeping last known snapshot AbortError
```

该日志发生在页面轮询请求超时/取消时，页面保留上一次快照，没有白屏。建议后续区分“主动取消”和“真实 API 失败”，避免持续输出警告。

## 阻塞与优先级

### P0

暂无。

### P1

1. 1280×720 视口下右侧 `AGV运输` 列表高度为 0，内容被父面板裁剪，用户无法查看或滚动 AGV 卡片。
2. API 轮询取消时持续打印 `AbortError` 警告，虽然有降级快照，但会干扰故障诊断。

### P2

1. 三维拖拽和滚轮已执行并保持渲染，但当前没有可自动读取的相机角度/缩放值，建议给场景控制增加测试观测接口或埋点。
2. 车间/分类导航按钮缺少稳定的选中语义，当前只能确认点击不崩溃，不能完全断言业务筛选结果。
3. 页面还没有 Playwright 测试依赖，当前浏览器回归依赖交互执行和 DOM 结果检查。

## 结论

核心页面、产线切换、设备选择、三维操作、输入控件和本地控制禁用策略均可执行。当前不建议宣称“前端交互全部验收通过”，原因是右侧 AGV 区域存在确定性的布局可见性问题，且缺少正式自动化浏览器测试。
