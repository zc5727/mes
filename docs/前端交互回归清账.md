### 回归结论

1. **不是已确认的 CSS 遮挡问题。** 当前页面结构和 DOM 定位正常。
2. **存在运行环境时序风险。** Vite 开发模式热更新期间曾出现 Pinia `storeToRefs` 异常并导致 DOM 短暂为空；此时用户会看到控件消失或不可操作。建议截图反馈先强制刷新，验收使用干净启动或生产预览。
3. 本次模式切换操作在浏览器会话中因页面 HMR/自动化会话超时未完成最终状态断言，不能把它记为通过；待前端修复 HMR 稳定性后重跑 API→local→API，并分别点击设备下拉、注入、仿真重置和新增产线。
